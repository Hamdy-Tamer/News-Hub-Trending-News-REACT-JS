# NewsHub US Network

NewsHub US Network is a modern, responsive news aggregator web application that delivers the latest news across business, technology, health, entertainment, sports, and science in the United States. Built with React and Bootstrap, it provides users with a clean, intuitive interface to stay informed about current events.

## 🌟 Features

- **Multi-Category News:** Browse news from Business, Technology, Entertainment, Health, Science, Sports, and General categories
- **Responsive Design:** Optimized for all devices from mobile to desktop
- **User Authentication:** Secure login and registration system
- **Real-time News:** Fetches latest headlines from NewsAPI
- **Modern UI/UX:** Clean, professional design with smooth animations
- **Category Filtering:** Easy navigation between different news types


## 🛠️ Built With

- **Frontend Framework:** React.js
- **Styling:** CSS3 with CSS Modules, Bootstrap
- **Icons:** Font Awesome
- **Form Handling:** Formik with Yup validation
- **HTTP Client:** Axios
- **Routing:** React Router
- **Notifications:** React Hot Toast
- **API:** NewsAPI


## 🚀 Usage

**Browse News**

- Navigate through different news categories using the navbar
- View article images, titles, descriptions, and publication dates
- Click "Read Full Article" to view the complete story on the source website

**Search Functionality**

- Use the search bar in the hero section to find specific news articles
- Results are filtered by article titles

**User Authentication**

- Register a new account with email, password, name, age, and phone number
- Login with existing credentials
- Logout to end your session


## 🎨 Customization

**Styling**

- Modify CSS modules in the respective .module.css files
- Update color schemes by changing gradient values in CSS files
- Adjust responsive breakpoints in media queries


 ## 📱 Responsive Design
 
The application is fully responsive and optimized for:

- 📱 Mobile devices (320px and up)
- 📟 Tablets (768px and up)
- 💻 Desktops (1024px and up)
- 🖥️ Large screens (1200px and up)
